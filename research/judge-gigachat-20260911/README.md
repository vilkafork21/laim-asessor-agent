# Research: качество судьи на GigaChat, сентябрь 2026

Ветка `research/judge-gigachat-20260911`. Исследование отвечает на вопрос владельца:
почему ассесор не обгоняет baseline моды и почему κ и α во многих случаях около нуля.

## Главные результаты

1. Сравнение accuracy с модой при редком дефекте тождественно проверке «точность тревог
   выше 50%»: `n · (accuracy_судьи − accuracy_моды) = TP − FP − M`. Recall в это сравнение
   не входит. Тождество проверено на всех строках test.
2. κ ≈ 0 имеет четыре разные причины, и все найдены в данных: судья-константа (κ = 0 ровно),
   слишком мало дефектов для оценки, ошибка старого scorer на дробных метках, ненадёжный
   человеческий эталон.
3. Лучший результат на независимом test — CI09997554: accuracy 0,982 против моды 0,927,
   κ = 0,879, найдены все 4 дефекта при одной ложной тревоге.
4. Требование обосновать оценку повышает recall, но и долю ложных тревог; привязка
   обоснования к идентификаторам пунктов рубрики возвращает precision.
5. Текст внутри оцениваемых данных способен управлять решением судьи.

## Воспроизведение

Данные, промпты, ответы модели и ключи в репозиторий не входят: это реальные обращения
клиентов. Пути к корзинам, traces и рабочему каталогу зашиты константами в начале
`prepare_cases.py`, `prepare_traces.py`, `analyze_gold.py`, `analyze_comparison.py`,
`analyze_native_panels.py` и `run_judge.py` — перед запуском их нужно поправить под своё
окружение. Учётные данные модели читаются из `.gigachat.env` рядом со скриптами;
этот файл в репозиторий не входит. Числовые результаты прогонов остаются вне Git.

```sh
python harness/prepare_cases.py        # корзины -> единицы с разбиением
python harness/prepare_traces.py       # реальные traces -> единицы без gold
python harness/run_judge.py            # основная серия
python harness/advance_experiments.py  # test-стадия и стресс-проверки
python harness/analyze_results.py --bootstrap
python harness/analyze_comparison.py
python harness/metric_theory.py        # тождество baseline и разрешающая способность κ
python harness/injection_experiment.py # граница данных против инъекции
```

## Границы

Это исследовательский групповой holdout на уже изученных источниках, а не независимая
сертификация. Embeddings недоступны (HTTP 402), поэтому все retrieval-плечи лексические.
Шесть пакетов не являются выборкой будущего потока. Числа разных экспериментов нельзя
складывать в один показатель качества.
