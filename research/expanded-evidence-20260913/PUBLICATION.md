# Publication format

Numeric JSON results in this Git directory are minified for transport; their parsed values are unchanged. The hashes in `results/reproducibility.json` refer to the original execution serializations. Running the supplied analysis produces those original formatted outputs, including `calibrated_vectors.json` for all five profiles.

`results/evaluation_vectors.json` contains all 96 human/A/B values and anonymous cluster numbers. Both original full judgment records (including non-sensitive compact decision grounds), matching the previously committed A/B seals, are retained in the downloadable research bundle. They are not private chain-of-thought. Client inputs, original IDs, traces, source text and credentials are not in Git or the bundle.

The supplied scripts reproduce numerical calculations and prepare inputs from the owner's original Parquet. They do not reproduce conversational model decisions by a new API call. The data source is a previously studied corpus; this is not a fresh test or production promotion.
